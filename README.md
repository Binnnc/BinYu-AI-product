# 于斌 - AI 产品经理作品集

这是用于 AIGC 内容产品经理、AI 创作工具产品经理和 AI 应用产品经理岗位投递的网页版作品集。

## 在线查看

投递与在线浏览链接：

```text
https://binnnc.github.io/BinYu-AI-product/
```

本地入口文件为：

```text
index.html
```

## 文件结构

```text
.
├── index.html
├── assets/
└── images/
```

请保持 `index.html`、`assets`、`images`、`videos` 在同一目录下，否则作品集中的图片、视频和本地动效资源可能无法正常加载。

启用 GitHub Pages 后，建议将成品链接放在简历和仓库 About 区，而不是让招聘者从仓库文件列表进入。

## 浏览方式

- 键盘方向键、空格或鼠标滚轮翻页
- 手机端左右滑动翻页
- 按 `Esc` 打开页面总览
- 按 `B` 切换静态模式，低性能设备建议使用静态模式
- 作品视频需要主动点击播放，不会自动播放或消耗流量
