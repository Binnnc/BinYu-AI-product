这是用于 AI 产品经理岗位投递的网页版作品集。

## 在线查看

如果部署到 GitHub Pages、Netlify、Vercel 或其他静态站点服务，入口文件为：

```text
index.html
```

## 文件结构

```text
.
├── index.html
├── assets/
└── images/
```

请保持 `index.html`、`assets`、`images` 在同一目录下，否则作品集中的图片和本地动效资源可能无法正常加载。
